# TBOX Voltage Remote App

这是一个用于通过蓝牙透传模块连接 TBOX/仪表链路的 Android 示例工程。应用支持 BLE 扫描、Nordic UART 透传、接收通知，以及发送 48V/60V/72V 选项对应的配置帧或自定义十六进制数据。

## 构建

1. 使用 Android Studio 打开本目录。
2. 等待 Gradle 同步完成。
3. 执行 `gradlew.bat assembleDebug`，生成 `app/build/outputs/apk/debug/app-debug.apk`。

项目包含本地 FastBleLib 模块和 AAR，便于在没有额外依赖时构建。

## 使用说明

- 默认 UUID 使用 Nordic UART Service：服务 `6E400001-B5A3-F393-E0A9-E50E24DCCA9E`，写入 `6E400002-B5A3-F393-E0A9-E50E24DCCA9E`，通知 `6E400003-B5A3-F393-E0A9-E50E24DCCA9E`。
- 若蓝牙模块资料给出了不同 UUID，可在应用内修改。
- 新配置帧、旧组合帧和原始 HEX 透传仅是根据现有资料整理的示例；实际设备可能需要不同的地址、长度、校验或授权流程。
